# README Visual Assets

This folder separates project evidence from explanatory visualisations.

## Project photographs and interface capture

- `cover.png` — completed physical prototype supplied by the project owner.
- `dashboard-live.webp` — live project dashboard capture supplied by the project owner.
- `electronics-controller.webp` — internal controller, interface board and wiring photograph supplied by the project owner.
- `electronics-sensor-stack.webp` — internal GNSS and sensor-mount photograph supplied by the project owner.

These images document the visible configuration only. They do not by themselves prove calibration, weatherproofing, field reliability or solar autonomy.

## Explanatory visualisations

- `application-rooftop.webp` — AI-generated application visualisation derived from the completed-prototype photograph. It illustrates an intended supervised rooftop use case and is not field-test evidence.
- `fusion-360-modeling.webp` — AI-generated design-process visualisation derived from the printed enclosure and assembled prototype. The repository's `.f3d` files, not the visualisation, are the editable CAD source.

Both visualisations were reviewed against the supplied prototype references before publication. No generated visual is used as evidence in the test matrix.
