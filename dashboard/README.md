# Dashboard and Data

This folder will define the data schema, ingestion pathway, visualisations, deployment instructions, and data-quality indicators.

The dashboard should distinguish measured data, derived values, missing data, sensor faults, and unverified readings. Store units, timestamps, timezone, sensor identity, firmware revision, and calibration metadata with the data.

The [v0.2 data schema](data-schema-v0.2.md) now defines the revision, evidence-level, sensor, power, local/remote logging and diagnostic fields used by the synthetic 72-hour preview.
