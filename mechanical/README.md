# Mechanical Design

This folder will contain editable CAD, neutral STEP exports, printable files, drawings, mounting details, enclosure notes, and fabrication settings.

The current [v0.2 enclosure and mounting specification](v0.2-enclosure-spec.md) defines the metrology/control/power zones, fabrication inputs and test sequence. It is a design preview; no geometry, print or environmental pass is claimed.

Outdoor design should explicitly consider water paths, condensation, UV exposure, drainage, ventilation/radiation shielding, cable strain relief, fastener corrosion, sensor placement, service access, and safe mounting.

Each released part should state its revision, units, material/process, orientation, tolerance-sensitive features, and relationship to the full assembly.
