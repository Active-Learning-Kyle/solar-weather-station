# Contributing

Thank you for helping improve the Solar Weather Station.

## Before changing the design

1. Open a GitHub Issue describing the problem or opportunity.
2. Link the relevant requirement, test, evidence, or source.
3. State the alternatives considered and the trade-off being proposed.
4. Record any safety, cost, compatibility, and licensing consequences.

## Making a change

1. Create a focused branch.
2. Make one coherent change.
3. Update documentation, BOM, and tests with the design.
4. Open a Pull Request and explain what changed, why, and how it was verified.

## Evidence standard

Screenshots can support a result, but raw data, test conditions, firmware version, hardware revision, and acceptance criteria are stronger evidence. Failed tests are valuable and should not be hidden.

## Student contributors

Use your own words, cite sources, follow third-party licences, and document significant AI assistance in `AI_USE.md`. AI may accelerate work; it does not own the engineering decision.
