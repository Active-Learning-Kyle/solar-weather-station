# Hardware

This folder will contain editable schematics, wiring diagrams, PCB sources, interface definitions, connector pinouts, electrical calculations, and hardware revision notes.

## Minimum evidence before release

- Exact part numbers and datasheets
- Power tree, protection, fusing, polarity, and grounding decisions
- Connector and pinout table
- RS-485 termination/bias/isolation decision
- Measured current in operating modes
- Assembly inspection checklist
- Hardware revision linked to test results

Do not upload only screenshots when an editable source format exists.
