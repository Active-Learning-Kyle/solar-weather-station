# Licence Review

No project-wide licence has been selected yet.

Before choosing one:

1. Identify every third-party code, hardware, CAD, image, and documentation source.
2. Record its exact version and licence in `THIRD_PARTY.md`.
3. Determine whether files were merely studied, copied, modified, or linked as dependencies.
4. Separate original work from third-party work when different licence terms apply.
5. Obtain appropriate legal or institutional guidance if compatibility is unclear.

Until this review is complete, the repository is publicly viewable but no permission beyond applicable copyright law is granted for reuse of original materials.
