# Gate D Decision-Alignment Review

Complete after the independent instructor and TA responses are locked.

## Required alignment

| Control question | Instructor | TA | Aligned? | Change if not aligned |
|---|---|---|---|---|
| Is there an immediate safety stop? | no in the synthetic case | | | stop criteria / scenario display |
| May the same configuration return outdoors unchanged? | no | | | continuation threshold / checklist |
| Decision category | revise | | | category definitions / evidence display |
| Who approves another field run? | instructor after reviewed evidence and site controls | | | escalation/authority guide |
| Is local-log recovery different from full-system success? | yes | | | dashboard/log-state presentation |

Technical repair ideas may differ. Gate D passes only when safety class, field-continuation permission and decision authority are consistent or the resulting control change is documented.

## Disagreement routing

| Disagreement | First thing to revise |
|---|---|
| `proceed` versus `revise` | acceptance threshold, unresolved-finding display and checklist wording |
| `revise` versus `return to bench` | definition of local versus systemic failure and required bench requalification |
| `revise` versus `reference only` | intended data-use/accuracy requirement and prototype role |
| Different safety class | stop criteria and hazard information immediately |
| Different decision owner | escalation and authority record |
