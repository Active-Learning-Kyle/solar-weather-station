## Planning time—measure rather than assume

| Activity | Initial allowance |
|---|---:|
| Bench check | 15–20 min |
| Installation plus initial data confirmation | 30–45 min; reserve 45–60 min for the first attempt |
| Daily site check | 10–15 min |
| Daily dashboard/log review | 5–10 min |
| Removal | 15–20 min |
| Post-retrieval inspection | 20–30 min |

Record actual duration and TA intervention in VAL-002/T-077 before scaling the workflow to multiple student teams.

## Role rule

- **Students own:** installation, checklist use, observation, basic data review, anomaly reporting, initial analysis and proposed changes.
- **TA owns:** verification and supervision, obvious-hazard check, anomaly classification support, escalation check and major-issue record—not the student's engineering decision.
- **Instructor owns:** deployment approval, safety criteria and significant continuation/restart decisions.
- **Venue/site role owns:** site permission and site-operation constraints.

Any student or TA may stop the test immediately when an immediate safety risk is identified.
