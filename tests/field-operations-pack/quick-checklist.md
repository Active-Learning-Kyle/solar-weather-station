# Quick Field Checklist

Use `Yes / No / N/A`. Any `No` on a safety/stop item means **do not deploy or stop the test** until the named responsible person reviews it.

## Before deployment

| Check | Yes / No / N/A | Evidence / action |
|---|---|---|
| Test purpose, configuration, start/stop decision and roles are named | | |
| Battery/supply show no swelling, leakage, damage or abnormal heat — **No: do not deploy** | | |
| Primary sensors output plausible values; logging and timestamps work | | |
| Network loss does not stop local logging; restart returns to logging | | |
| Enclosure/connectors show no visible ingress path or exposed wettable live connection — **No: do not deploy** | | |
| Mounting is secure; no fall/trip/public-contact risk — **No: do not deploy** | | |
| Site permission, access, contacts, weather envelope and safe-removal method are confirmed | | |
| Reference/comparison method and required tools/spares are available | | |
